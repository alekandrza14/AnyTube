Как загрузить видео на AnyTube

AnyTube не хранит видео у себя. Все ролики лежат в ваших публичных репозиториях GitHub, а сайт сам находит их и показывает. Ваш канал — это ваш GitHub-аккаунт.

Главное правило

Имя репозитория должно начинаться с anytubevideo_. Пример: репозиторий anytubevideo_myvideo с файлом myvideo.mp4 появится на сайте как ваш_ник/anytubevideo_myvideo.

Поддерживаемые форматы: .mp4 (лучше всего, H.264 + AAC), .webm, .mov, .m4v, .ogg.

Способ 1. Через сайт GitHub (без программ)

  1. Войдите на github.com и нажмите New repository.
  2. Имя: anytubevideo_название (например anytubevideo_my_trip). Видимость — Public.
  3. В поле Description напишите заголовок — он станет названием видео.
  4. Нажмите Create repository → uploading an existing file, перетащите видео и нажмите Commit changes.
Через браузер GitHub принимает файлы до 25 МБ. Для больших видео используйте способ 2.

Способ 2. Через Git (файлы до 100 МБ)

git clone https://github.com/ВАШ_НИК/anytubevideo_myvideo.git
cd anytubevideo_myvideo
copy C:\путь\к\myvideo.mp4 .      # на Linux/macOS: cp ~/myvideo.mp4 .
git add myvideo.mp4
git commit -m "Добавил видео"
git push

Способ 3. Большие видео (больше 100 МБ) — Git LFS

GitHub не принимает обычные файлы больше 100 МБ. Используйте Git LFS — AnyTube понимает такие файлы автоматически.

git lfs install
git lfs track "*.mp4"
git add .gitattributes myvideo.mp4
git commit -m "Видео через LFS"
git push
Бесплатная квота Git LFS у GitHub ограничена по месту и трафику. Если видео перестало грузиться — скорее всего, квота исчерпана. Лучше сжимать ролики перед загрузкой.

Сжать видео перед загрузкой (ffmpeg)

ffmpeg -i input.mov -c:v libx264 -crf 26 -preset slow -vf "scale=-2:720" -c:a aac -b:a 128k -movflags +faststart myvideo.mp4

-movflags +faststart важен: видео начнёт играть сразу, не дожидаясь полной загрузки.

Альтернатива: тег (topic)

Если не хотите менять имя репозитория, добавьте ему topic anytubevideo: на странице репозитория нажмите ⚙ рядом с About → Topics.

Как попасть в топ

Главная по умолчанию показывает Топ: чем больше звёзд (★ Star) у репозитория на GitHub, тем выше видео. При равном числе звёзд выше то, что обновлялось позже. Понравилось видео — откройте его репозиторий кнопкой «GitHub» и поставьте звезду. Вкладка Новые сортирует только по дате.

Когда видео появится?

Список обновляется раз в 10 минут. Поиск GitHub иногда индексирует новые репозитории с задержкой — до нескольких часов.

Несколько видео в одном репозитории

Можно. Каждый видеофайл в репозитории (в том числе в папках) станет отдельным видео. Но заголовок из Description общий, поэтому для разных роликов удобнее отдельные репозитории — тогда у каждого своё название.

Как удалить видео

Удалите файл или весь репозиторий, либо сделайте его приватным. С сайта видео пропадёт при следующем обновлении.

Правила

Загружайте только то, на что у вас есть права. Контент обязан соответствовать правилам GitHub.
