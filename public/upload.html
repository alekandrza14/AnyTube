Как загрузить видео на AnyTube

AnyTube не хранит видео у себя. Все ролики лежат в ваших публичных репозиториях GitHub, а сайт сам находит их и показывает. Ваш канал — это ваш GitHub-аккаунт.

Главное правило

Имя репозитория должно начинаться с anytubevideo_. Пример: репозиторий anytubevideo_myvideo с файлом myvideo.mp4 появится на сайте как ваш_ник/anytubevideo_myvideo.

Поддерживаемые форматы: .mp4 (лучше всего, H.264 + AAC), .webm, .mov, .m4v, .ogg.

Самый простой способ: AnyTube Uploader (Windows)

⬇ Скачать AnyTube Uploader

  1. Распакуйте архив и запустите AnyTube.cmd (или перетащите видео прямо на него).
  2. Программа сама скачает всё нужное: Python, Git, Git LFS и FFmpeg.
  3. Один раз вставьте токен GitHub: github.com/settings/tokens/new → Tokens (classic) → галочка public_repo.
  4. Выберите видео и введите название. Репозиторий anytubevideo_… создастся сам.

Форматы .mov, .mkv, .avi и другие конвертируются в MP4.

Очень большие видео: нарезка на части

Видео любого размера Uploader режет на пронумерованные части без перекодирования и потери качества:

myvideo.part0001.mp4
myvideo.part0002.mp4
myvideo.part0003.mp4 …

На сайте части играют подряд как одно видео: следующая включается сама, а под плеером есть список частей для перехода.

  • Части по ~95 МБ (рекомендуется): обычные файлы без Git LFS, поэтому квота LFS не тратится.
  • Части по 1.9 ГБ через Git LFS: частей меньше, но тратится квота LFS.

Части складываются в репозитории-тома: первый — anytubevideo_myvideo, следующие — anytubevideo_myvideo_vol2, _vol3… (до ~900 МБ в каждом). В главном репозитории лежит файл anytube.json со списком всех частей. Тома отдельно в ленте не показываются.

Ограничения AnyTube

⏱ Длительность видео — не больше 1 года (365 дней). Более длинные видео Uploader не загружает, а сайт не показывает.

📝 Описание — до 1 000 000 000 символов (один миллиард). Длинное описание тоже делится на пронумерованные файлы description.part0001.txt, part0002… по 10 миллионов символов. На сайте оно подгружается порциями кнопкой «Показать ещё».

Комментарии

Комментарий — это репозиторий в аккаунте того, кто его пишет:

ваш_ник/anytubecomment_автор-видео_myvideo.mp4_Comment.1

Uploader создаёт его сам: «Написать комментарий» → вставьте ссылку на видео → текст. Номер растёт сам (Comment.2, Comment.3…). Короткий текст хранится в описании репозитория, полный — в comment.md. Удалить комментарий = удалить репозиторий.

Дизлайки: 5 уровней

Дизлайк — это тоже репозиторий в аккаунте того, кто его ставит. Число перед .diske — уровень:

ваш_ник/anytubecomment_автор-видео_myvideo.mp4_Commet.3.diske
  1. 😕 Ну не очень
  2. 😒 Так себе
  3. 👎 Плохо
  4. 😖 Очень плохо, зря потратил время
  5. 🤮 Это убогий видос, мой день испорчен

От одного человека к одному видео засчитывается один дизлайк. Uploader при повторном дизлайке меняет уровень (переименовывает репозиторий). Своему видео дизлайк не засчитывается. Убрать дизлайк — удалить этот репозиторий.

🛒 Продажа: видео, приложения, обои

В AnyTube Uploader отметьте нужное:

  • Платное видео: цена за час просмотра (например 6 ₽/час, списывается поминутно, пока видео играет) и/или покупка навсегда. Первые секунды (трейлер) видны всем бесплатно.
  • 📦 Мы рекламируем приложение: ролик бесплатный, а приложение — бесплатно, покупкой или по подписке на час / день / месяц / год.
  • 🖼 Анимированные обои: бесплатно (скачивается оригинал, в том числе GIF) или платно (на сайте только превью).

Платные файлы хранятся в ваших приватных репозиториях anytubepaid_…. Uploader сам даёт сайту доступ к ним, покупатели скачивают через сайт после оплаты. Для продажи нужен токен с галочкой repo. Вы получаете 63% от каждой продажи (комиссия AnyTube — 37%) на заработанный баланс букса.

💰 Букс: продвижение видео и заработок

В буксе автор пополняет рекламный баланс через ЮMoney и запускает рекламу своего видео: выбирает время просмотра и число показов. Зрители смотрят такие видео нужное время и получают деньги на баланс, а потом выводят их на ЮMoney по заявке. Вход через GitHub.

Способ 1. Через сайт GitHub (без программ)

  1. Войдите на github.com и нажмите New repository.
  2. Имя: anytubevideo_название (например anytubevideo_my_trip). Видимость — Public.
  3. В поле Description напишите заголовок — он станет названием видео.
  4. Нажмите Create repository → uploading an existing file, перетащите видео и нажмите Commit changes.
Через браузер GitHub принимает файлы до 25 МБ. Для больших видео используйте способ 2.

Способ 2. Через Git (файлы до 100 МБ)

git clone https://github.com/ВАШ_НИК/anytubevideo_myvideo.git
cd anytubevideo_myvideo
copy C:\путь\к\myvideo.mp4 .      # на Linux/macOS: cp ~/myvideo.mp4 .
git add myvideo.mp4
git commit -m "Добавил видео"
git push

Способ 3. Большие видео (больше 100 МБ) — Git LFS

GitHub не принимает обычные файлы больше 100 МБ. Используйте Git LFS — AnyTube понимает такие файлы автоматически.

git lfs install
git lfs track "*.mp4"
git add .gitattributes myvideo.mp4
git commit -m "Видео через LFS"
git push
Бесплатная квота Git LFS у GitHub ограничена по месту и трафику. Если видео перестало грузиться — скорее всего, квота исчерпана. Лучше сжимать ролики перед загрузкой.

Сжать видео перед загрузкой (ffmpeg)

ffmpeg -i input.mov -c:v libx264 -crf 26 -preset slow -vf "scale=-2:720" -c:a aac -b:a 128k -movflags +faststart myvideo.mp4

-movflags +faststart важен: видео начнёт играть сразу, не дожидаясь полной загрузки.

Альтернатива: тег (topic)

Если не хотите менять имя репозитория, добавьте ему topic anytubevideo: на странице репозитория нажмите ⚙ рядом с About → Topics.

Как попасть в топ

Главная по умолчанию показывает Топ: чем больше лайков ❤ у видео на AnyTube, тем выше. Лайк ставится кнопкой ❤ под видео, входить через GitHub не нужно, повторное нажатие убирает лайк. Звёзды GitHub на топ не влияют. Вкладка Новые сортирует только по дате.

Когда видео появится?

Список обновляется раз в 10 минут. Поиск GitHub иногда индексирует новые репозитории с задержкой — до нескольких часов.

Несколько видео в одном репозитории

Можно. Каждый видеофайл в репозитории (в том числе в папках) станет отдельным видео. Но заголовок из Description общий, поэтому для разных роликов удобнее отдельные репозитории — тогда у каждого своё название.

Как удалить видео

Удалите файл или весь репозиторий, либо сделайте его приватным. С сайта видео пропадёт при следующем обновлении.

Правила

Загружайте только то, на что у вас есть права. Контент обязан соответствовать правилам GitHub.
